# Entrada de audios

Victor deja aquí los audios largos de ElevenLabs (uno por serie). Claude los recoge solo,
renderiza, sube y programa. No hace falta avisar.

Nombres: que el archivo lleve el nombre de la serie, por ejemplo
`historia.mp3`, `biblia.mp3`, `salud.mp3`, `nutricion.mp3` (sirve cualquier nombre que contenga la serie).

Cuando un audio se procesa, Claude lo mueve a `<serie>/<episodio>/audio.mp3` y esta carpeta queda vacía.
